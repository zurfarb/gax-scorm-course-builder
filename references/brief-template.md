# Brief template

Template for `<course>/brief.md` (step 1). It records what the user asked for, so the concept can be checked against it later. Write it in German. Mark every assumption with *(Annahme)*; each assumption also goes to "Offene Fragen" in the concept.

```markdown
# Brief: <Thema>

## Anfrage

> <the user's request, quoted word for word>

## Eckdaten

| | |
|---|---|
| Thema | <…> |
| Zielgruppe und Vorwissen | <…> |
| Ziel: Was können die Lernenden danach? | <…> |
| Dauer | <…> |
| Sprachen | de-CH, en-GB *(Annahme, falls nicht genannt)* |
| LMS | <…> |

## Muss rein

- <…>

## Soll nicht rein

- <…>

## Material

| Datei | Inhalt | Verlässlichkeit |
|---|---|---|
| input/<datei> | <ein Satz> | offiziell / Entwurf / Synthese |
```
